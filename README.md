# Mohamed Samir | Portfolio

My personal portfolio: a place to present my work, experience and skills, built to be explored rather than just scrolled.

## About

I wanted this portfolio to do two things at once: be clear and professional about what I do, and feel a little different from a standard page of text and cards. So alongside the usual content you will find small interactive details and a few playful surprises. They are meant to make the visit more enjoyable, never to get in the way of the information.

Everything is written by hand with plain HTML, CSS and JavaScript. There is no framework and no build step.

## What's inside

| Section | Purpose |
| --- | --- |
| Introduction | Who I am and how to reach me |
| About | A more personal look at who I am |
| Career | Roles and internships with responsibilities and achievements |
| Projects | Selected work, filterable by topic, with the problem, solution and my contribution |
| Skills | Languages, frameworks, tools and platforms I work with |
| Certificates | Certifications and courses, previewed directly from the PDFs |
| Contact | A message form that delivers straight to my inbox |

## Tech stack

- **HTML5, CSS3 and vanilla JavaScript (ES6+)** for all the structure, styling and behaviour
- **Bootstrap 5** for the grid and base styles
- **Swiper** for the certificates carousel
- **PDF.js** to render certificate previews
- **EmailJS** to send messages from the contact form without a backend
- **`<model-viewer>`** and **Lottie** for 3D models and animations
- **Google Fonts** for typography

## Engineering notes

- **Fast first load.** Only the top of the page is built on load. Each section is set up as you scroll toward it, and libraries such as Swiper, PDF.js and EmailJS are downloaded only when their section needs them.
- **Responsive by design.** The layout adapts across screen sizes (see below). The experience is designed around larger screens, so on phones the site shows a short notice with links to my CV and profiles.
- **Accessibility.** Semantic landmarks, descriptive alt text, labelled controls, and keyboard support for the main interactions.
- **Plain CSS.** One stylesheet organised in the same order as the page, with no preprocessor.

### Responsive behaviour

| Screen width | Experience |
| --- | --- |
| 992px and up | Full desktop layout |
| 481px to 991px | Tablet layout |
| 480px and below | Notice recommending a laptop or PC, with links to my CV and profiles |

## Browser support

Current versions of Chrome, Edge, Firefox and Safari. A few animations use modern CSS (container query units), which need Chrome 105+, Safari 16+ or Firefox 110+.
